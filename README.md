# Redux Authentication UI

React practice project with login and profile components and Redux store integration. This is a state-management example, not a production authentication system.

## Project structure

- `src/components/Login.jsx`
- `src/components/Profile.jsx`
- `src/redux/store.js`

## Getting started

Install Node.js and npm, then run:

```bash
git clone https://github.com/JAYANTI-THAKOR-941/redux-auth.git
cd redux-auth
npm install
npm run dev
```

Open the development URL displayed in the terminal.
